## Executive Summary

BrandOS v3.0 is a comprehensive product redesign inspired by Chronicle HQ's presentation editor. The goal is to transform the Brand Guides experience from a static page viewer into a **live, editable, presentation-grade document editor** — where every element on every slide is directly clickable, editable, and customizable.

The redesign covers:
1. **Editor UX** — Chronicle-style slide editor with inline text editing
2. **Bottom Toolbar** — Insert / Remix / Theme / Background paradigm
3. **Three Layers of Customization** — Settings, Customization, Editor
4. **Export System** — PDF, PowerPoint, Image, Social formats
5. **App-wide UI Simplification** — Cleaner, simpler, more focused

## Chronicle Analysis — What Makes It Great

### Core UX Patterns Observed

| Feature | How Chronicle Does It | Our Adaptation |
|---------|----------------------|----------------|
| **Slide Canvas** | Full-screen slide with dark workspace around it | Same — slide centered on dark/neutral bg |
| **Inline Editing** | Click any text → floating toolbar (heading/size/font/align/color) | Same — contentEditable + floating toolbar |
| **Bottom Bar** | Insert / Remix / Theme / Background — always visible | Same layout, adapted for brand context |
| **Top Bar** | Breadcrumb (Doc / Chapter X of Y) + Share / Export / Present | Same — Brand / Page X of Y + actions |
| **Left Nav** | Collapsible slide thumbnails (vertical dots, expand to thumbs) | Same — dot indicators expand to thumbnails |
| **Theme Panel** | Left drawer: "This chapter" / "Whole document" tabs, theme presets | Same — per-page or whole-doc theme control |
| **Background Panel** | Popover: Color picker, gradient, image + Position controls | Same — color/gradient/image bg per slide |
| **Insert Menu** | Paragraph, Heading, Media, Card, Chart, Table, Mockup, Embed, Diagrams, + Add slide | Adapted — Text, Heading, Image, Shape, Logo, Chart, + Add page |
| **Remix** | Template gallery with categories (Type, Title, Intro, Agenda, etc.) | Same — template remix per page type |
| **Export** | PDF, PowerPoint, Image (3840x2160), LinkedIn/Instagram/X post, GIF | Same formats |
| **Present** | Full-screen presentation mode | Already have this |

### Key Design Decisions

1. **Dark workspace, light/dark slides** — The editor background is always dark (#1a1a1a), slides float on it
2. **No sidebar in editor mode** — Clean, focused canvas. Sidebar only for navigation
3. **Floating toolbar on selection** — Appears above selected text, disappears when deselected
4. **Bottom bar is the command center** — All creation/customization starts here
5. **Chapters = our slides/pages** — Each "chapter" is one guideline page

## Three Layers of Customization

### Layer 1: Brand Settings (Global)
**Where:** Brand Kit → Settings  
**What changes:** Brand name, logo, colors, fonts, tone, audience  
**Scope:** Affects ALL brand outputs — guidelines, templates, exports  
**UX:** Form-based editor (current approach is fine)

### Layer 2: Document Customization (Per-Document)
**Where:** Brand Guides → Customize button  
**What changes:** Which pages to include, page order, theme preset, page numbering, brand mark visibility, document title, version text  
**Scope:** Affects the entire guideline document  
**UX:** Side panel with toggles and controls (current CustomizePanel, improved)

### Layer 3: Per-Page Editor (Per-Slide)
**Where:** Clicking on any slide in Brand Guides  
**What changes:** Text content, text styling, background color/image, element position, add/remove elements  
**Scope:** Affects only that specific page  
**UX:** Chronicle-style inline editing with floating toolbar + bottom bar

## User Stories

### US-1: First-time brand owner
> "I just created my brand. I want to generate professional guidelines in 1 click, then customize them."

**Flow:** Dashboard → Brand → Brand Guides → Pick template → Customize → Export PDF

### US-2: Designer refining guidelines
> "I want to edit specific slides — change text, swap backgrounds, adjust typography — without leaving the app."

**Flow:** Brand Guides → Click slide → Edit inline → Change background → Export

### US-3: Client presentation
> "I need to present these guidelines to my client in a meeting."

**Flow:** Brand Guides → Present button → Full-screen slideshow

### US-4: Marketing team member
> "I need to export this as Instagram-sized images for social media."

**Flow:** Brand Guides → Export → Instagram post (1080x1350) → Download

## Architecture Changes

### Current State
```
BrandGuidesPage → TemplateDocument → PageFrame → [static page components]
```

### Target State
```
BrandGuidesPage
├── EditorWorkspace (dark canvas)
│   ├── TopBar (breadcrumb + actions)
│   ├── SlideCanvas (centered, editable)
│   │   ├── EditableElements (contentEditable text, draggable)
│   │   └── FloatingToolbar (on selection)
│   ├── LeftNav (slide dots / thumbnails)
│   └── BottomBar (Insert / Remix / Theme / Background)
├── CustomizeDrawer (document-level settings)
└── ExportModal (multi-format)
```

### Key Components to Build
1. `EditorWorkspace` — Dark canvas container
2. `EditableSlide` — Slide with contentEditable elements
3. `FloatingToolbar` — Text formatting toolbar
4. `BottomBar` — Insert / Remix / Theme / Background
5. `ThemeDrawer` — Per-chapter or whole-doc theming
6. `BackgroundPopover` — Color / gradient / image picker
7. `InsertMenu` — Element insertion dropdown
8. `RemixModal` — Template gallery for remixing pages
9. `ExportModal` — Multi-format export (PDF, PPTX, PNG, Social)
10. `SlideNavigator` — Left-side dot/thumbnail nav

## Implementation Phases

### Phase 1: Editor Workspace Shell
- Dark workspace container
- TopBar with breadcrumb + Share/Export/Present
- BottomBar with Insert/Remix/Theme/Background buttons
- SlideNavigator (left dots)
- Current slides render inside the new shell

### Phase 2: Inline Editing
- contentEditable on text elements within slides
- FloatingToolbar on text selection (heading/size/font/align/color)
- Click-to-edit, click-away-to-deselect

### Phase 3: Bottom Bar Panels
- Theme drawer (per-page / whole-doc, presets)
- Background popover (color swatches, gradients, position)
- Insert menu (text, heading, image, shape, logo)
- Remix modal (template gallery to swap page layout)

### Phase 4: Export System
- PDF (current, improved resolution)
- Image (3840x2160 high-res)
- Social formats (LinkedIn 1080x1080, Instagram 1080x1350, X 1200x675)
- Animated GIF option

### Phase 5: App-wide UI Polish
- Simplify navigation
- Consistent dark workspace feel
- Remove visual clutter
- Improve spacing and typography

## Non-Goals for v3.0

- PowerPoint export (complex, future)
- AI generation of slide content (future, but Insert menu has placeholder)
- Custom fonts upload (future)

- User can change background of any page
