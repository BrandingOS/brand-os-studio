## What's New

### Brand Guides Editor (Chronicle-Inspired)
A full-screen, dark-canvas presentation editor for brand guidelines.

- **Dual canvas modes:** Slide (freeform zoom/pan) and Scroll (vertical document)
- **36 guideline slides** per brand, organized into sections
- **4 template systems:** Studio, Identity, Noteform, Signal — each with entirely different visual DNA
- **Inline block editing:** Click any text/image element → floating toolbar → edit in place
- **Bottom bar:** Insert / Remix / Colouring / Background (matches Figma design)
- **Left sidebar:** 5 icon buttons — Pages, Layers, Search, Duplicate, Add Page
- **Magnetic scroll:** Smooth snap transitions between slides
- **Canvas zoom:** Ctrl+scroll, pinch, +/- buttons, auto-fit on load
- **Presentation mode:** Full-screen with keyboard navigation
- **PDF/PNG export:** Multi-page PDF at 3x resolution, single-slide PNG at 4x
- **Browser back blocked:** No accidental navigation from trackpad swipes

### Floating Toolbar (Per-Element)
- **Text:** Type toggle (Heading/Paragraph), font weight, font size, color picker, alignment, bold, italic
- **Image:** Type toggle, replace, crop, fit, fullscreen
- **All blocks:** Turn Into menu, duplicate, delete, opacity, more options

### Bottom Bar Panels
- **Insert:** Paragraph, Heading, Image, Card, Embed, Mockup, Quote, Sticky note, Diagrams + Add structure
- **Remix:** 9 layout templates with visual thumbnails
- **Colouring:** Per-chapter/whole-document themes (Chronicle, Minimal, New classic, Retro tech)
- **Background:** 4 tabs (Backgrounds/Overlays/Upload/Generate), color dots, gradient grid, blur toggle

### Guideline Pages (36 per template)
Cover, Brand Overview, Introduction, Core Values, Brand Purpose, Brand Archetype, Logo System, Logo Construction, Color System, Color Ratio, Gradient System, Dark Mode, Pattern System, Typography, Type Specimen, Voice & Tone, Voice DNA, Brand Manifesto, Icon System, Visual Direction, Brand Universe, Motion Principles, Touchpoints, Stationery, Digital Product, Colophon, Closing

### Architecture (v3.0)
- DI container with service contracts
- Brand validation engine (WCAG contrast, logo safety)
- Color engine (HSL/RGB, harmonies, shades, palette validation)
- 23 unit tests (ServiceContainer + Color Engine)
- Vitest test infrastructure
- Clean barrel exports
- Zustand decoupled from services

### Other Improvements
- SKAM brand added (with real SVG logo from website)
- Brand Assets manager (upload, URL, embed)
- Logo export at up to 8000px with PDF option
- Brand Voice, Strategy, Typography modules
- Customization panel (slide visibility, chrome, text, layout)
- All Brand Kit downloads working (PNG, SVG, PDF)
- QR codes using real encoding library
- Animation video export
