Naming reference

Name Scope Size What it is
AppRail workspace + brand 88px wide The single global navigation rail. Icon + label stacked, never icon-only. Its item set is scope-aware — workspace items in the dashboard, brand items inside a brand. Brand switcher in the top slot, Settings + UserMenu at the bottom.
BrandNavbar brand only h-14 Slim topbar inside a brand. Shows Brand · Section breadcrumb + search + notifications/help.
DashboardNavbar workspace only h-14 Slim topbar in the workspace. Workspace label + search + theme toggle + notifications/help.
EditorRail editor only ~56px Editor mode/tool rail. Existing — unchanged in this redesign.
EditorTopBar editor only h-12 Editor topbar (back · title · save state · share). Existing — unchanged in this redesign.

Mental model

Rail

Vertical, sits on the left. AppRail, EditorRail.

Navbar / TopBar

Horizontal, sits on top. BrandNavbar, DashboardNavbar, EditorTopBar.

There is only one primary rail in this product: AppRail. It changes its items based on context. There is no separate brand sidebar component.

The shells (layout wrappers that mount the bars)

ShellMountsUsed by
DashboardShell / DashboardLayout AppRail (workspace mode) + DashboardNavbar Workspace pages (Home, Brands, Learn, Settings, marketplace)
BrandLayout AppRail (brand mode) + BrandNavbar All brand pages (Overview, Setup, Guidelines, Folders, Brand Kit, Designs, Templates)
EditorShell EditorRail + EditorTopBar Editors (unchanged in this redesign)

How to phrase requests

Instead of "add an item to the left nav"
Say "add an item to AppRail in workspace mode" or "in brand mode"
Instead of "move the brand switcher"
Say "the brand switcher lives in AppRail's top slot — change X about it"
Instead of "shrink the topbar inside a brand"
Say "shrink BrandNavbar"
Instead of "change the dashboard topbar"
Say "change DashboardNavbar"
Instead of "the brand sidebar should…"
Say "AppRail in brand mode should…" (there is no separate brand sidebar)
